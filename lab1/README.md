1. Постановка задачи
Реализовать алгоритм перемножения двух квадратных матриц на языке C++ без использования сторонних библиотек и без распараллеливания. Провести замеры времени выполнения для матриц размером 200, 400, 800, 1200, 1600 и 2000. Осуществить автоматизированную верификацию результатов с помощью сторонних инструментов (Python/NumPy).

2. Описание реализации
Язык программирования: C++
Алгоритм: Классический тройной вложенный цикл.
Оптимизация: Компиляция с флагом -O2.
Верификация: Скрипт на Python (библиотека NumPy), который генерирует случайные матрицы, запускает C++ программу, вычисляет эталонное произведение и сравнивает результаты с учетом погрешности.
